# Μηνυσάκιας

Ένας ιστότοπος όπου ο πολίτης περιγράφει το πρόβλημά του με απλά λόγια και η τεχνητή νοημοσύνη τού εξηγεί πώς
μπορεί να κινηθεί νομικά: μήνυση ή έγκληση, αγωγή, εξώδικο, καταγγελία σε αρχή — με τα βήματα, τις προθεσμίες και
παραπομπές σε άρθρα των ελληνικών κωδίκων που μπορεί να ανοίξει και να διαβάσει.

Γενική νομική πληροφόρηση, όχι νομική συμβουλή.

## Πώς δουλεύει

```
μήνυμα πολίτη
   │
   ▼
1. Δρομολογητής (μοντέλο, JSON)   ποια άρθρα ρυθμίζουν το ζήτημα; + 3–6 αναζητήσεις με τις λέξεις του νόμου
   │
   ▼
2. Συλλογή νόμων (τοπικά, BM25)   τα άρθρα που ονόμασε ο δρομολογητής + τα καλύτερα κάθε αναζήτησης (έως 24)
   │
   ▼
3. Συντάκτης (μοντέλο, ροή)       γράφει την απάντηση πάνω στα άρθρα, με παραπομπές [ΠΚ 308]
   │
   ▼
ιστότοπος: η απάντηση όπως γράφεται· κάθε παραπομπή ανοίγει το κείμενο του άρθρου
```

- **Μοντέλα**: ανοιχτά μοντέλα σε πάροχο εντός ΕΕ, μέσω OpenAI-compatible API — προεπιλογή το GLM-5.3 Flash στο
  TensorX (Ιρλανδία). Πάροχος εκτός ΕΕ απορρίπτεται, εκτός αν οριστεί ρητά `MINISAKIAS_REQUIRE_EU=0`.
- **Νόμοι**: 6.334 άρθρα από 21 κώδικες και το Σύνταγμα, από το
  [lexifina/greece-law](https://github.com/lexifina/greece-law), «ψημένα» μέσα στην εφαρμογή (`data/laws/`). Η
  αναζήτηση τρέχει τοπικά (BM25 πάνω σε ελληνικά θέματα λέξεων) — χωρίς vector database, χωρίς εξωτερική υπηρεσία.
- **Απόρρητο**: τίποτα από όσα γράφει ο πολίτης δεν αποθηκεύεται ούτε καταγράφεται. Η συνομιλία ζει στον περιηγητή
  (sessionStorage) και στέλνεται ολόκληρη με κάθε ερώτηση. Χωρίς cookies, χωρίς analytics, χωρίς τρίτους.

## Εκκίνηση

```bash
python -m venv .venv && . .venv/bin/activate
pip install -e ".[dev]"
```

Χωρίς κλειδί, για να δείτε τον ιστότοπο (η αναζήτηση άρθρων είναι πραγματική, η απάντηση όχι):

```bash
MINISAKIAS_DEMO=1 uvicorn minisakias.server:app --port 8000
```

Με μοντέλο:

```bash
cp .env.example .env        # και συμπληρώστε TENSORX_API_KEY
uvicorn minisakias.server:app --env-file .env --port 8000
```

Ανοίξτε το http://localhost:8000. Το `/health` δείχνει τι τρέχει (μοντέλα, πάροχος, συλλογή).

## Ρυθμίσεις

Όλες από το περιβάλλον· ο πλήρης κατάλογος με σχόλια είναι στο [.env.example](.env.example). Οι κυριότερες:

| Μεταβλητή | Προεπιλογή | Τι κάνει |
| --- | --- | --- |
| `TENSORX_API_KEY` | — | το κλειδί του παρόχου (το μόνο απαραίτητο) |
| `MINISAKIAS_MODEL` | `z-ai/glm-5.3-flash` | το μοντέλο του συντάκτη |
| `MINISAKIAS_ROUTER_MODEL` | το ίδιο | το μοντέλο του δρομολογητή |
| `MINISAKIAS_EFFORT` / `MINISAKIAS_ROUTER_EFFORT` | `high` / `low` | το `reasoning_effort` κάθε βήματος |
| `MINISAKIAS_RATE_PER_WINDOW`, `…_WINDOW_S`, `…_PER_DAY` | 6 / 300 / 40 | ερωτήσεις ανά διεύθυνση IP |
| `MINISAKIAS_DEMO` | 0 | λειτουργία επίδειξης χωρίς μοντέλο |

## Η συλλογή νόμων

`data/laws/articles.jsonl` (ένα άρθρο ανά γραμμή) και `data/laws/codes.json` (ένας κώδικας ανά εγγραφή) χτίζονται
από το `tools/sync_laws.py`. Για ενημέρωση από το upstream:

```bash
python tools/sync_laws.py        # sparse clone μόνο των codes/ και constitution/ (το πλήρες repo είναι ~10 GB)
pytest
```

**Τα όρια της συλλογής — διαβάστε τα πριν εμπιστευτείτε τις απαντήσεις:**

- Οι περισσότεροι κώδικες υπάρχουν στο upstream **όπως αρχικά δημοσιεύθηκαν**, όχι όπως ισχύουν σήμερα: ο Αστικός
  Κώδικας είναι το κείμενο του 1984, ο ΚΠολΔ του 1985, ο ΚΟΚ του 1999· ο Ποινικός Κώδικας και ο ΚΠΔ έχουν τις
  τροποποιήσεις μόνο έως το 2019. Κωδικοποιημένοι (ενημερωμένοι) είναι μόνο οι φορολογικοί κώδικες και το Σύνταγμα.
- Ο ΑΚ, ο ΚΠολΔ, ο ΚΟΚ, ο ΚΔΔιαδ και ο ΚΔΔ προέρχονται από **OCR** σαρωμένων ΦΕΚ, με λάθη στα γράμματα, και από τον
  ΚΠολΔ λείπουν άρθρα.
- Λείπουν οι ειδικοί νόμοι (ενδοοικογενειακή βία, προστασία καταναλωτή, μισθώσεις, προσωπικά δεδομένα κ.ά.) και η
  νομολογία.

Η εφαρμογή δεν το κρύβει: κάθε κώδικας κουβαλά μια σημείωση έκδοσης που ο συντάκτης διαβάζει μαζί με τα άρθρα (και
έχει οδηγία να λέει πότε ένα κείμενο είναι παλιό και τι γνωρίζει ότι άλλαξε), η ίδια σημείωση εμφανίζεται όταν ο
πολίτης ανοίγει ένα άρθρο, και η σελίδα `/oroi` έχει τον πίνακα όλων των κωδίκων. Όταν το upstream ενσωματώσει τις
τροποποιήσεις, αρκεί να ξανατρέξει το `sync_laws.py`.

## Deploy (Fly.io)

Ένα Docker image, ένα μηχάνημα στη Φρανκφούρτη — [Dockerfile](Dockerfile), [fly.toml](fly.toml):

```bash
fly launch --no-deploy --copy-config --name <όνομα-εφαρμογής>
```

```bash
fly secrets set TENSORX_API_KEY=...
```

```bash
fly deploy --ha=false
```

Το όριο ερωτήσεων μετριέται στη μνήμη κάθε μηχανήματος· με περισσότερα μηχανήματα χρειάζεται κοινό μετρητή.

## Tests

```bash
pytest
```

```bash
ruff check .
```

Τα tests δεν καλούν πάροχο: ο δρομολογητής και ο συντάκτης αντικαθίστανται, και οι κλήσεις προς το API ελέγχονται
απέναντι σε ψεύτικο OpenAI-compatible endpoint (τι στέλνεται, πώς διαβάζεται η ροή, πώς μεταφράζονται τα σφάλματα).

## Πριν από τη δημόσια λειτουργία

- Συμπληρώστε τα στοιχεία του υπευθύνου λειτουργίας στο `src/minisakias/web/oroi.html` και δώστε το κείμενο των όρων
  σε νομικό για έλεγχο (GDPR: τα προβλήματα των πολιτών συχνά αφορούν ποινικά ή ευαίσθητα δεδομένα).
- Δοκιμάστε πραγματικές ερωτήσεις με δικηγόρο δίπλα σας: το pipeline δεν έχει ακόμη βήμα ελέγχου της απάντησης.
